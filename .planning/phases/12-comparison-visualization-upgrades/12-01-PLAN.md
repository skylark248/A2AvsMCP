    6. Helper `compareFields(l, r): { equal: boolean; diffs: string[] }` — iterate union of own keys, skip IGNORE_FIELDS, compare via `JSON.stringify((l as any)[k]) !== JSON.stringify((r as any)[k])`, collect differing key names.

    7. `export function alignTraces(left: TraceEvent[], right: TraceEvent[]): DiffRow[]` body:
       - Bucket each side by `${turnIndexOf(e)}::${e.event_type}` into `Map<string, TraceEvent[]>` (lists, not sets — preserve duplicates).
       - For each key in `new Set([...lb.keys(), ...rb.keys()])`: pair index-by-index until min(len) reached; surplus on left → `removed`, surplus on right → `added`.
       - For paired (l, r): run compareFields. If equal → `matched-equal`. Else → `matched-divergent`, with `divergenceCause = "fault"` iff `isTraceFailureEvent(l) !== isTraceFailureEvent(r)` OR any name in `diffs` starts with `"fault_"`; else `divergenceCause = "field"`. Set `differingFields: diffs`.
       - Final sort: `(a, b) => a.turnIndex - b.turnIndex || ORDER[a.status] - ORDER[b.status]` where `ORDER = { "matched-equal": 0, "matched-divergent": 1, "removed": 2, "added": 3 }` (UI-SPEC line 211).

    8. Add a JSDoc block above `alignTraces` that explicitly documents the within-turn pairing rule (Pitfall 8): "Within a (turn_index, event_type) bucket events pair by arrival order. If a turn emits the same event_type multiple times in different orders across protocols, divergence may surface as matched-divergent rows even when both sides did the same work — by design for v1."

    9. Do NOT add any React, MUI, or DOM code in this file. Pure TypeScript only. No default export.
