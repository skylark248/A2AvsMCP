## Spacing Scale

MUI spacing unit = 8px (`theme.spacing(1) === 8px`). All `sx` values map to multiples below.

| Token | Value | MUI `spacing()` | Usage |
|-------|-------|-----------------|-------|
| xs | 4px | `0.5` | Gutter chip inner padding, arrow-label gap, diff row inner left padding |
| sm | 8px | `1` | Stack spacing between diff rows, sequence-diagram lifeline tick spacing |
| md | 16px | `2` | Header toggle group padding, row vertical padding, lane-header column padding |
| lg | 24px | `3` | Lifeline horizontal spacing in sequence diagram (column width = 24 × 8 = 192px max) |
| xl | 32px | `4` | Vertical margin above/below the diff/sequence component within its parent surface |
| 2xl | 48px | `6` | Top of lifelines to first message arrow (gives lane-header label room) |
| 3xl | 64px | `8` | Not used in this phase |

Exceptions:
- Sequence diagram SVG arrow click hit-area: minimum 24px tall (a11y minimum click target). Visible arrow stroke is 1.5px; the transparent hit `<rect>` is 24px. (Multiple of 4: 24px.)
- Diff gutter chip column: 28px wide. (Multiple of 4.)

## Component Inventory

Two net-new components. Both built from MUI primitives + project utilities. No third-party additions (D-85).

### `AnnotatedDiffView.tsx` (VIZ-01)

**Location:** `frontend/src/components/traces/AnnotatedDiffView.tsx`

**Props interface:**
```ts
interface AnnotatedDiffViewProps {
  leftEvents: TraceEvent[];   // Trace A (typically MCP)
  rightEvents: TraceEvent[];  // Trace B (typically A2A)
  leftProtocolLabel?: string; // default: "MCP — Trace A"
  rightProtocolLabel?: string; // default: "A2A — Trace B"
  pinnedEventId?: string | null; // shared with TraceExplorer for cross-view highlight
  onPinEvent?: (eventId: string | null) => void;
}
```

**Internal data shape (Claude's discretion, D-discretion):**
```ts
type DiffStatus = "added" | "removed" | "matched-equal" | "matched-divergent";
interface DiffRow {
  status: DiffStatus;
  left?: TraceEvent;
  right?: TraceEvent;
  turnIndex: number;
  divergenceCause?: "fault" | "field" | undefined; // drives border color override
}
```

**Layout:**
- Header strip (40px): left "Trace A" column header + right "Trace B" column header in two `Grid size={6}` columns. Each header carries `Typography variant="overline"` in protocol color and a `Chip size="small"` showing event count.
- Body: virtualized scroll container (re-uses `CompareTracesPanel` sync-scroll pattern; CSS `display: grid; grid-template-columns: 28px 1fr 28px 1fr;` — gutter | left row | gutter | right row). Each `DiffRow` renders as one grid row spanning all 4 columns.
- Gutter chip cells: 28px wide, render `+` (added, `success` tint), `−` (removed, `error` tint), `≠` (matched-divergent, `warning` tint), or empty (matched-equal).
- Row labels: `traceLabel(event)` from `lib/trace/utils.ts` (role-first, D-78). Body2, weight 400.
- Expandable payload: each row reveals `JsonTree` via right-side disclosure caret. Collapsed by default.

**Empty state:** when `leftEvents.length === 0 && rightEvents.length === 0`, render centered `Typography variant="body2" color="text.disabled"`: `"Run both protocols to compare traces."`

**Error state:** if alignment throws (e.g. malformed event), render `Alert severity="error"` at top of view: `"Could not align traces — event missing turn_index. Re-run the scenario or check the trace file."`

**Card chrome:** rows have no border per row; outer container uses MUI `Paper` with `elevation={0}` + `border: "1px solid rgba(16,32,51,0.08)"` (matches MuiCard override). `borderRadius: 2`.

### `SequenceDiagramView.tsx` (VIZ-02)

**Location:** `frontend/src/components/traces/SequenceDiagramView.tsx`

**Props interface:**
```ts
interface SequenceDiagramViewProps {
  events: TraceEvent[];
  pinnedEventId?: string | null;
  onPinEvent?: (eventId: string | null) => void;
  protocol?: "mcp" | "a2a" | "hybrid"; // drives default arrow stroke
}
```

**Rendering technique (D-79):** pure SVG, hand-rolled. Single `<svg>` root with absolute-positioned `<g>` lanes + `<g>` arrows. No `@xyflow/react`, no `motion` unless reduced-motion off (D-85).

**Lane model (D-80):** 5 fixed roles in fixed left-to-right order — `User`, `Orchestrator`, `LLM`, `Tool`, `Remote Agent`. Lifelines rendered as 1px dashed lines from y=48 (below header) to y=canvas height. Lane header at y=24 uses `Typography variant="overline"` rendered as SVG `<text>`.

**Arrow geometry:**
- Source lane → target lane horizontal line, with arrowhead at target.
- Stroke width: 1.5px (visible) over 24px transparent `<rect>` hit-area (a11y minimum, see Spacing exception).
- Stroke color: protocol color via `getProtocolColor(traceEventProtocol(event))`. Faults override to `toneColor.warning`.
- Arrow label: event role-first label, body2 14px, positioned above the arrow midpoint, max-width 240px with `text-overflow: ellipsis`.
- Self-message (source === target): rendered as a small loop on the right side of the lifeline (24px loop, same protocol color).

**Vertical layout:** events stacked top-to-bottom in `events[]` order. Row height = 32px (multiple of 4). Total SVG height = `48 + events.length * 32 + 32` (header + rows + footer pad).

**Pinned-event highlight (D-82):** when `event.id === pinnedEventId`, the arrow line gets a 2px stroke (instead of 1.5px), a `secondary.main` outline rect (4px padding around hit-area), and a `Chip label="Pinned" size="small" color="secondary"` rendered as `foreignObject` to the right of the arrow label.

**Click-to-pin behavior:** clicking the arrow's hit-area calls `onPinEvent(event.id)`. Clicking the same arrow again calls `onPinEvent(null)` (toggle off). Clicking another arrow replaces the pin.

**Reduced-motion (D-83):**
- `useMediaQuery('(prefers-reduced-motion: reduce)')` gates all transitions.
- When `reduce`: no arrow draw-in animation, no scroll easing on pin-to-row, no arrow-label fade-in. Static render.
- When motion permitted: 200ms ease-out arrow draw-in on initial mount only; pin-toggle updates are instant. No looping animations.

**Empty state:** when `events.length === 0`, centered `Typography variant="body2" color="text.disabled"`: `"No events to diagram. Run the scenario to populate."`

**Error state:** if any event fails actor classification, render `Alert severity="warning"` above the SVG: `"Some events couldn't be placed on a lifeline — see console for details."` (Continue rendering placeable events.)

## Interaction Contract

### View toggle (both surfaces)
- MUI `ToggleButtonGroup`, `size="small"`, `exclusive`. Two buttons.
- Selected state: `primary.main` background, white text.
- Unselected state: transparent bg, `text.primary`.
- Keyboard: arrow-left / arrow-right cycles selection (MUI native).
- ARIA: `aria-label="View mode"` on the group; each button has `aria-pressed` set automatically.
- Persistence: not persisted across sessions (component-local `useState`). Defaults are "Side-by-side" and "List" respectively.

### Diff alignment (VIZ-01)
- Pure function, no async. Compute on render via `useMemo([leftEvents, rightEvents])`.
- Algorithm: bucket events by `turn_index`, then within each bucket pair by `event_type` (D-74). Unmatched on either side → added/removed. Matched events compared field-by-field; if any non-trivial field differs → matched-divergent. Trivial fields (timestamps, run_id, lane) excluded from comparison.
- Output: `DiffRow[]` flattened in turn-index order. Within a turn bucket: matched-equal first, then matched-divergent, then added/removed.

### Diff row interactions
- Click a row: expands inline `JsonTree` for both left and right events side-by-side. Other rows can be expanded simultaneously (no auto-collapse).
- Hover on gutter chip: `Tooltip` with divergence cause copy (see Copywriting).
- No click-to-pin in Diff view (pinning is a TraceExplorer-only concept; Compare context already implies a separate pinning mental model — out of scope).

### Sequence diagram interactions (VIZ-02)
- Click an arrow: pins the event (D-82). Pinned event id propagates to the parent `TraceExplorer`.
- Click the same arrow again: unpins.
- Click empty SVG canvas: no-op (does NOT clear the pin — prevents accidental clearing).
- Toggle to "List" view: scrolls the list to the pinned event id (use `scrollIntoView({ behavior: prefersReducedMotion ? 'auto' : 'smooth', block: 'center' })`) and applies a 2px `secondary.main` outline on that row for 1.5s (or instantly + persistent until next pin change when `reduce`).

### Focus / a11y
- View toggle: native MUI keyboard support.
- Diff rows: `role="row"` with `tabIndex={0}`. Enter/Space toggles JSON expansion.
- Sequence-diagram arrows: SVG arrow hit-area is `<rect>` with `role="button"`, `tabIndex={0}`, `aria-label="{actor source} → {actor target}: {event label}, turn {turn_index}"`. Enter/Space pins the event.
- Lifelines: decorative; `aria-hidden="true"`.
- Pinned-event announcement: `aria-live="polite"` region announces `"Pinned: {role-first label}, turn {turn_index}"` on pin change.
- Reduced-motion: honored via `useMediaQuery('(prefers-reduced-motion: reduce)')` — gates arrow draw-in animation, scroll easing, and any motion library use (D-83, Phase 8 baseline).
