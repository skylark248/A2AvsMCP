**Interfaces:**
```typescript
interface TimelineBar {
  agent: string;
  offset: number;    // ms from earliest start — invisible spacer bar (Gantt technique)
  duration: number;  // ms — visible colored bar
  color: string;
}

interface ParallelAgentTimelineProps {
  events: TraceEvent[];
  mode: string;
}
```

**Data transformation function `buildTimelineBars`:**
1. First try parallel events: filter events where `parallel_batch_id` AND `started_at` AND `completed_at` are all defined.
2. If parallel events found: compute `minStart = Math.min(...started_at values)`. For each event, create a bar with `agent = traceEventActor(event)`, `offset = started_at - minStart`, `duration = completed_at - started_at`, `color = getProtocolColor(mode)`.
3. If NO parallel events: fall back to sequential mode per D-05. Filter events with `step_index != null`, sort by `step_index`. Compute `minTs = first event's timestamp_ms`. For each event, `offset = timestamp_ms - minTs`. Duration = gap to next event's timestamp_ms, or 50ms for the last event. Use a minimum duration of 20ms to keep bars visible. Color = `getProtocolColor(mode)`.
4. If neither yields bars, return empty array.

**Component body:**
```typescript
export function ParallelAgentTimeline({ events, mode }: ParallelAgentTimelineProps) {
  const bars = useMemo(() => buildTimelineBars(events, mode), [events, mode]);

  if (bars.length === 0) return null;

  const barHeight = 28;
  const chartHeight = bars.length * (barHeight + 12) + 40;

  return (
    <Box>
      <Typography variant="caption" sx={{ color: "text.secondary", mb: 0.5, display: "block" }}>
        Agent Timeline
      </Typography>
      <ResponsiveContainer width="100%" height={chartHeight}>
        <BarChart layout="vertical" data={bars} barSize={barHeight} margin={{ top: 5, right: 20, bottom: 5, left: 10 }}>
          <XAxis type="number" domain={[0, "dataMax"]} tickFormatter={(v: number) => `${v}ms`} />
          <YAxis type="category" dataKey="agent" width={100} tick={{ fontSize: 12 }} />
          <Tooltip
            formatter={(value: number, name: string) =>
              name === "offset" ? ["", ""] : [`${value}ms`, "Duration"]
            }
            labelFormatter={(label: string) => `Agent: ${label}`}
          />
          {/* Invisible offset bar — Gantt spacer (RESEARCH.md Pitfall 1) */}
          <Bar dataKey="offset" stackId="timeline" fill="transparent" isAnimationActive={false} />
          {/* Visible duration bar */}
          <Bar dataKey="duration" stackId="timeline" isAnimationActive={false}>
            {bars.map((bar, i) => (
              <Cell key={i} fill={bar.color} />
            ))}
          </Bar>
        </BarChart>
      </ResponsiveContainer>
    </Box>
  );
}
```

Key details:
- Uses `layout="vertical"` for horizontal bars per D-04
- Uses stacked bar technique (invisible offset + visible duration) for Gantt-style rendering per RESEARCH.md
- Named export (project convention)
- `isAnimationActive={false}` to keep the timeline snappy
- Tooltip hides the offset bar value
