## Component Inventory

All net-new for Phase 11. Existing MUI primitives only — no new third-party components.

### `DiscoveryPhasePanel.tsx`

**Location:** `frontend/src/features/traces/components/DiscoveryPhasePanel.tsx`

**Props interface:**
```ts
interface DiscoveryPhasePanelProps {
  mcpEvents: TraceEvent[];   // filtered to event_type === "tool_discovery" && protocol === "mcp"
  a2aEvents: TraceEvent[];   // filtered to event_type === "tool_discovery" && remote_agent tag
  scenario: string;          // gate check — render only when scenario === "tool_discovery"
  defaultExpanded?: boolean; // default: true (open)
}
```

**Layout:** MUI `Accordion` (default expanded = true per researcher discretion, D-discretion).
- `AccordionSummary`: `ExpandMoreIcon` + `Typography variant="h6"` "Discovery Phase" + `Chip` count badges for MCP tools found / A2A agents found.
- `AccordionDetails`: `Grid container spacing={3}` with two `Grid size={{ xs: 12, md: 6 }}` columns — MCP column (left) and A2A column (right).

**MCP column:**
- Header: `Typography variant="overline"` "MCP — Tool Catalog" in `color: protocolColor.mcp` (#1976d2). Left-edge `Box` with 4px border-left in `protocolColor.mcp`.
- Body: one `Card` per tool discovered (`event.tools[]` array entries). Each card shows: tool name (`body2`, weight 600), description (`body2`, weight 400, `color: text.secondary`), timestamp `caption` right-aligned. If `inputSchema` present, collapsible `Accordion` (nested, compact) renders JSON via `JsonTree` helper extracted from `ProtocolEnvelopeDrawer`.
- Empty / placeholder: when `mcpEvents.length === 0`, render a dimmed `Box` with `Typography variant="body2" color="text.disabled"` — copy: `"Run on MCP to populate"` (D-71).

**A2A column:**
- Header: `Typography variant="overline"` "A2A — Agent Cards" in `color: protocolColor.a2a` (#7b1fa2). Left-edge `Box` with 4px border-left in `protocolColor.a2a`.
- Body: one `Card` per `tool_discovery` event tagged `remote_agent`. Each card shows: agent name (`body2`, weight 600), skills list as `Chip` row (`size="small"`, `variant="outlined"`), timestamp `caption` right-aligned. If `a2a_agent_card.skills[]` present, render skill names as chips.
- Empty / placeholder: when `a2aEvents.length === 0`, render `Typography variant="body2" color="text.disabled"` — copy: `"Run on A2A to populate"` (D-71).

**Timestamp format:** `+{ms}ms` relative to first discovery event in the panel (not wall clock). `caption` variant, right-aligned, `color: text.secondary`.

**Card chrome:** MUI `Card` with `border: "1px solid rgba(16,32,51,0.08)"` and `boxShadow: "0 18px 40px rgba(23,39,60,0.08)"` — inherited from `MuiCard` override in `appTheme`. `borderRadius: 2` (16px, consistent with lane card convention).

**Failure-signal row highlight:** if the discovery event carries `event_type === "tool_discovery"` AND the payload indicates stale-cache or fallback (`requested_transport !== transport`, or `tools.length === 0` after a non-empty request), render a 2px left-border in `toneColor.warning` (#ed6c02) on the affected card + `WarningAmberRoundedIcon` (`fontSize: "small"`) beside the timestamp.

## Interaction Contract

### Accordion expand/collapse
- Default: expanded (`defaultExpanded={true}`). Executor may expose `defaultExpanded` prop for future configurability (deferred per D-discretion).
- Collapse animation: `prefers-reduced-motion` respected — MUI Accordion already honors this via `disableGutters` / `TransitionProps={{ unmountOnExit: true }}`.
- Keyboard: MUI Accordion handles Enter/Space on `AccordionSummary` natively. No additional key binding.

### Tool card expand (nested schema)
- `inputSchema` accordion: default collapsed. User expands to see JSON tree.
- The `JsonTree` component from `ProtocolEnvelopeDrawer` should be extracted into `frontend/src/lib/trace/JsonTree.tsx` and imported by both `ProtocolEnvelopeDrawer` and `DiscoveryPhasePanel`. Do NOT duplicate the implementation.

### Placeholder column (single-protocol load, D-70/D-71)
- The dimmed placeholder column is non-interactive. `pointer-events: none` not required (no click targets).
- No routing from within the placeholder. No inline run button (D-71 locked).

### Scroll behavior
- `DiscoveryPhasePanel` is above `TraceExplorer`. No scroll synchronization between panel and explorer needed. Panel height is content-driven; no `maxHeight` clamp on the panel itself (TraceExplorer on CompareTracesPanel already has its own `maxHeight: 600` scroll container).

### Focus / a11y
- `AccordionSummary` receives `aria-expanded` from MUI automatically.
- Each tool/agent `Card` inside the panel: not focusable itself. If nested schema accordion exists, its `AccordionSummary` is keyboard-focusable.
- `Chip` labels for skills: `aria-label` not required (short labels are self-describing). If a chip is truncated, add `title` attribute via MUI `Chip` `title` prop.
- Protocol column headers: use `Typography component="h3"` with `variant="overline"` so screen readers get semantic heading structure within the panel.
