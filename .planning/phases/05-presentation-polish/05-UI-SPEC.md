## Spacing Scale

MUI default spacing is 8px per unit (`theme.spacing(1) = 8px`). All Phase 5 insertions follow the existing MUI `sx` prop scale used throughout the codebase.

| Token | MUI `spacing()` | px Value | Usage |
|-------|-----------------|----------|-------|
| xs | 0.5 | 4px | Icon gaps, inline padding, badge inner padding |
| sm | 1 | 8px | Chip label padding, stack gaps within a row |
| md | 2 | 16px | Card content padding, element spacing |
| lg | 3 | 24px | Section padding inside result cards |
| xl | 4 | 32px | Layout gaps between result cards |
| 2xl | 6 | 48px | Major section breaks (page-level) |
| 3xl | 8 | 64px | Page-level top/bottom spacing |

Exceptions:
- GlossaryTerm dotted underline uses `borderBottom: '1px dashed currentColor'` — not a spacing value, a border style.
- MUI Tooltip uses its own internal padding (not overridden).
- Failure chip row uses `flexWrap: 'wrap'` with `useFlexGap` — gap of 4px (xs) between chips.
- Touch target minimum: 44px height for all interactive Chip elements (MUI default meets this for `size="medium"`; `size="small"` Chips are display-only and do not require tap target sizing).

Source: Existing codebase patterns in `RunWorkspacePage.tsx`, `TraceExplorer.tsx`, `AppShell.tsx` (verified).

## Component Inventory

New components introduced in Phase 5:

### GlossaryTerm (new)
- File: `frontend/src/components/glossary/GlossaryTerm.tsx`
- Element: `<span>` with `borderBottom: '1px dashed currentColor'`, `cursor: 'help'`, wrapped in MUI `Tooltip` (D-03, D-04)
- Props: `term: string` (slug key), `children: React.ReactNode`
- Tooltip: `title={definition}` where definition is a plain string from `glossaryTerms.ts`; `arrow={true}`
- No font changes, no color changes on the span — inherits surrounding text style

### GlossaryTerms map (new static data)
- File: `frontend/src/lib/glossary/glossaryTerms.ts`
- Type: `Record<string, string>` — slug key to one-sentence definition
- 17 terms: `mcp`, `a2a`, `tool_call`, `task_submit`, `agent_card`, `transport`, `broker`, `specialist_agent`, `parallel_dispatch`, `step_index`, `parallel_batch_id`, `discovery_phase`, `execution_phase`, `mock_runtime`, `llm_runtime`, `baseline`, `hybrid`
- All definitions are plain strings — no HTML, no JSX
- Module-level const — no async, no fetch, no useEffect

### Runtime Chip (modification to RunWorkspacePage)

### Latency badge (modification to TraceExplorer)

## Interaction Contract

### GlossaryTerm hover
- Trigger: mouse hover over dotted-underline span
- Response: MUI Tooltip appears within ~300ms (MUI default `enterDelay`)
- Tooltip placement: MUI default (top, shifts if near edge)
- Tooltip content: plain text — one-sentence definition
- Keyboard: MUI Tooltip is focusable; Tab into span shows tooltip on focus
- Touch: MUI Tooltip shows on press-and-hold (MUI default touch behavior)
- Dismiss: mouse-out or Tab away

### Runtime Chip
- Non-interactive — display only (`clickable` not set)
- Renders in the same `Stack` row as the transport badge Chip
- No state change on click
- Amber (`color="warning"`) for OpenAI; grey (`color="default"`) for mock

### Latency badge in TraceExplorer
- Non-interactive — display only
- Visible only when `runtime === "llm"` prop is truthy
- Positioned in the header stats row (same row as existing Chip summary stats)

### LLM Alert banner
- Non-interactive — display only (no dismiss button)
- Visible only when `runtime !== "mock" && runtime !== undefined`
- Renders at top of TraceExplorer accordion content, above event list

### Failure summary chips
- Non-interactive — display only
- Renders only when `item.failures.length > 0`
- Each chip label is a string from `item.failures[]` — server-generated, not user input

### GlossaryTerm wrapping — first mention rule
- Exactly one `<GlossaryTerm>` per protocol term per page/view
- The first occurrence shows the role-first full form: `<GlossaryTerm term="mcp">Tool Access Protocol (MCP)</GlossaryTerm>`
- Subsequent occurrences on the same page: plain text, no wrapping
- Pages where role-first applies: Run page (`RunWorkspacePage.tsx`), Compare page (`ComparePage.tsx`)
- Pages NOT changed: Learning, Reports, Traces, Trends, Presentation, Telemetry

## Animation Contract

Phase 5 uses `motion` (framer-motion 12.38.0) for one optional enhancement only:

- **TalkingPointCard entrance**: `initial={{ opacity: 0, y: 8 }}`, `animate={{ opacity: 1, y: 0 }}`, `transition={{ duration: 0.25 }}` — applied when the card first renders. Skip if implementation adds complexity.
- All other Phase 5 elements: no animation. Tooltips, chips, banners, and failure sections use MUI's default zero-delay rendering.

Animation is at Claude's discretion (per CONTEXT.md). If `motion` wrapping creates TypeScript complexity with MUI Paper, skip it and render the card statically.
