| T-10-05-02 | Information Disclosure | <img alt> text exposes run_id | accept | Same disclosure as the URL itself; no new surface. |
| T-10-05-03 | Denial of Service | mobile triggers Playwright spawn on cache miss | mitigate | OG_RENDER_LOCK serializes; cache hit on subsequent requests; 503 on render failure handled by `onError` (image hides). |
| T-10-05-04 | Spoofing | onError handler runs on broken-image event | accept | Standard browser event; element is hidden, no script execution beyond the inline handler which only mutates style. |
