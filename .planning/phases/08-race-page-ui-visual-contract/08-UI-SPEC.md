## Spacing Scale

Declared values (multiples of 4). MUI spacing unit = 8px → MUI `sx` tokens map directly.

| Token | Value | MUI sx | Usage |
|-------|-------|--------|-------|
| xs | 4px | 0.5 | Icon gaps, badge internal padding, dashed underline offset |
| sm | 8px | 1 | Compact element spacing, pill horizontal padding |
| md | 16px | 2 | Default element spacing, lane-card internal padding |
| lg | 24px | 3 | Section padding, banner vertical padding |
| xl | 32px | 4 | Layout gaps, between lanes at tablet breakpoint |
| 2xl | 48px | 6 | Major section breaks (between banner and methodology) |
| 3xl | 64px | 8 | Page-level vertical spacing, heatmap top margin |

Exceptions:
- Touch targets for all interactive cells (heatmap cells, pill badges): minimum 44px height (WCAG 2.5.5 AA). Source: UIRACE-06.
- Scrubber track: minimum 40px height for thumb hit area (D-49).
- Status strip: 48px height — fixed, not derived from scale.

## Typography

All sizes from `frontend/src/app/theme.ts`. Body/label sizes are MUI defaults (16px / 0.875rem).

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 16px (1rem) | 400 (regular) | 1.5 | Lane event feed, methodology prose, popover definitions |
| Label | 14px (0.875rem) | 400 (regular) | 1.4 | Metric ticker sub-labels ("TTFF", "Recovery Rate"), badge text, heatmap cell recovery-rate fraction |
| Heading | 18.4px (1.15rem) | 700 (bold) | 1.2 | Lane name headers (h3), section titles |
| Display | 25.6px (1.6rem) | 700 (bold) | 1.2 | Characteristic-failure banner h2 (dynamic clause + static header) |

Notes:
- Banner h1 maps to h2 in theme (1.6rem/700). The banner element uses `<h1>` semantically (ARIA landmark `role="banner"`) but receives h2 visual size to preserve hierarchy proportion on the dense race layout.
- Ticker value (live metric number): 18.4px (1.15rem) / 700 — label-above-value pattern per UIRACE-03; value uses Heading size, label uses Label size.
- Italic dynamic clause in banner: same size/weight as parent (1.6rem/700) + `font-style: italic`. Source: UIRACE-03.
- Replay pill text: 14px (0.875rem) / 700 — `text-transform: uppercase; letter-spacing: 0.08em` ("REPLAY · run abc123"). Source: D-49. Visual distinction provided by uppercase + tracking, not size reduction.
- TODO-06 (real display typeface) deferred to v2.1+ — do not substitute font in Phase 8.

Warm accent (`#b85c38` / secondary.main) reserved for:
- Replay state pill in status strip (D-49)
- "directional · n=3 tasks · v1" heatmap pill (Phase 9 / HEAT-01 — defined here for contract continuity)

- Scrubber auto-advance animation: disabled

## Page Layout Contract

### Information Hierarchy (top to bottom) — UIRACE-01

```
[AppBar — sticky, inherited from AppShell]
[RaceStatusStrip — 48px, session-level metadata: page-state label + replay pill + reconnect indicator]
[ReplayScrubber — below strip, only in replay mode (D-49)]
[Three-lane row — 1200px centered column, CSS flex row, gap=xl(32px)]
  [LaneCard: pure_mcp | pure_a2a | hybrid]
    [Lane stripe — 4px left border, protocol color]
    [Lane header: name chip + current-state indicator]
    [Ticker grid: label-above-value pairs (TTFF, Recovery Rate, Turns, Score)]
    [FailureStateBadge — below ticker, hidden until lane reaches terminal state]
    [Event feed — scrollable, aria-live="polite" for fault_observed]
[CharacteristicFailureBanner — full-width, 0px radius, 4px primary left rule, h2 + italic clause]
[MethodologySection — flat (no Paper/Card), background=dominant]
[HeatmapScaffold — CSS Grid, rows=HardnessType, cols=lanes; heatmap-empty shows muted scaffold + overlay]
```

### Central Column Width

- Desktop (≥1200px): `maxWidth: 1200`, centered, three-lane `flex-direction: row`
- Tablet (768-1199px): same column, lanes shrink proportionally (flex, no wrap), metrics compacted
- Small-tablet (480-767px): metrics compacted to 2-column grid within each lane
- Mobile (<480px): RacePage renders `?mode=summary` redirect trigger — Phase 8 ships the viewport check + `<CircularProgress />` placeholder while handoff to Phase 10 is pending

## Interaction Contract

### Tab Order (keyboard navigation — UIRACE-06)

1. AppBar nav links
2. Status strip controls (Launch Race CTA, if present)
3. Heatmap grid (first cell receives focus; arrow keys move within grid)
4. Glossary term spans (Tab stops for all first-mention `<span>` elements)
5. Replay scrubber thumb (when in replay mode)
6. "Got it" button in open Popover (focus trapped in Popover until dismissed)

### Focus Visible

All interactive elements: `outline: 3px solid #17475f; outline-offset: 2px` on `:focus-visible`. Widens to 4px under `prefers-contrast: more`.

### aria-live Regions

| Region | Element | Rate | Trigger |
|--------|---------|------|---------|
| `fault_observed` announcements | `aria-live="polite"` div inside each lane event feed | immediate | Each `fault_observed` ws event |
| Scrubber turn announcements | `aria-live="polite"` div below scrubber | throttled 200ms during drag; full on release | `turn_index` change (D-49) |
| WS reconnect status | `aria-live="polite"` in status strip | immediate | State transitions: `ws-disconnected` → `ws-reconnecting` → live |

### ARIA Landmarks

| Element | Role |
|---------|------|
| AppBar | `role="banner"` (via `<header>`) |
| Lane row + all race content | `role="main"` |
| Heatmap grid | `role="grid"` + `aria-label="Hardness vs Failure Heatmap"` |
| Heatmap cells | `role="gridcell"` |
| Methodology section | `role="complementary"` (`<aside>`) |

### Popover Interaction (D-50)

- First mention of glossary term: dashed underline (`border-bottom: 1px dashed currentColor`), `cursor: help`, click opens MUI `<Popover>` with full definition + "Got it" `<Button>` (variant="contained", size="small").
- Popover anchor: `anchorOrigin={{ vertical: "bottom", horizontal: "left" }}`, `transformOrigin={{ vertical: "top", horizontal: "left" }}`.
- "Got it" dismiss closes Popover and marks term as seen in `FirstMentionProvider` Set.
- Subsequent mentions: existing MUI `<Tooltip>` on hover only (no click handler).

### Heatmap Cell Interaction (D-46)

- Tab → first cell; arrow keys navigate within grid.
- Enter / Space: opens MUI `<Tooltip>` with recovery rate detail ("12/15 runs recovered").
- No click-to-drilldown in Phase 8 (per out-of-scope: "Per-cell heatmap drilldown to full trace").

## Glossary Extension (UIRACE-07)

8 new terms to add to `frontend/src/lib/glossary/glossaryTerms.ts`. All follow existing `Record<string, string>` pattern.

| Term key | Definition |
|----------|-----------|
| `ttff` | "Time to first fault — the elapsed milliseconds from run start until the first injected fault event lands in the trace." |
| `recovery_rate` | "The fraction of runs in which the agent fully recovered from an injected fault, expressed as a count (e.g. 12/15)." |
| `hardness_profile` | "A structured description of the difficulty characteristics of a task — which hardness types apply and at what intensity." |
| `recovered` | "A fault classification tag: the agent detected the fault and returned to a correct execution path within K=3 turns." |
| `gave_up` | "A fault classification tag: the agent detected the fault and abandoned the task rather than attempting recovery." |
| `kept_going_without_noticing` | "A fault classification tag: the agent did not acknowledge the fault and continued executing as if nothing had changed." |
| `kept_going_to_failure` | "A fault classification tag: the agent continued past the fault point and ultimately produced an incorrect or failed result." |
| `indeterminate` | "A fault classification tag: the available trace evidence was insufficient to assign any of the four primary recovery tags." |

First-mention scope: Race page only (`/race` + `/race/:run_id`). `FirstMentionProvider` wraps these routes. Set resets on route exit. No sessionStorage/localStorage (D-51).
