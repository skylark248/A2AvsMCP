Retry classifier shape (RESEARCH §2 D-38):

```
async def _run_one_with_retry(lane, task_spec, run_id, recorder, failure_script, sonnet_client, hybrid_plan):
    runner = _RUNNERS[lane]
    last_exc = None
    for attempt in range(3):
        try:
            return await asyncio.wait_for(
                runner(task_spec, run_id, recorder, failure_script, sonnet_client, **(
                    {"hybrid_plan": hybrid_plan} if lane == "hybrid" else {}
                )),
                timeout=PER_RUN_TIMEOUT_S,
            )
        except TRANSIENT_RETRY_TYPES as exc:
            last_exc = exc
            await asyncio.sleep(2 ** attempt + random.uniform(0, 1))
            continue
        except asyncio.TimeoutError:
            return _build_lane_failed_result(run_id, lane, task_spec, reason="timeout")
        # InjectedFaultError NOT caught — bubbles up. Runner already records done event.
    # Exhausted retries on transient.
    return _build_lane_failed_result(run_id, lane, task_spec, reason=type(last_exc).__name__)
```

CRITICAL constraints (audit-grade):
- ContextVar cleanup MUST be in try/finally — Semaphore re-uses workers and a leaked ACTIVE_FAULTS token will pollute the next run on the same task slot.
- The retry classifier tuple is CLOSED — no `except Exception` fallback. If a new transient type appears, the harness fails loudly and we add it explicitly.
- `InjectedFaultError` is intentionally absent from the tuple. Adding it would silently mask the very faults the race is testing (Plan 11 test_harness.py asserts this invariant).
- `fault_observed` events are forwarded to ws_emitter without filtering. Phase 6 D-08 NEVER_COALESCE already includes `fault_observed`; D-41 reaffirms.
- `race_done` is the ONLY harness-emitted event. Per-run events (`fault_injected`, `fault_observed`, `tool_call`, `agent_msg`, `done`) come from recorders inside runners.
