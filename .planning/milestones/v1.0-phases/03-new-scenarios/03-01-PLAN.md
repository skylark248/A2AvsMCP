| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01-01 | Tampering | scenarios.json seed file | accept | Static file in repo; no runtime write path; SHA-256 rebuild check detects accidental corruption on startup |
| T-03-01-02 | Information Disclosure | talking_point exposed in API response | accept | Content is static presenter notes; no PII, no secrets |
| T-03-01-03 | Denial of Service | Malformed talking_point dict (missing keys) | mitigate | TicketResponse uses TalkingPointResponse(BaseModel) — Pydantic validates structure at serialization time; None is accepted, malformed dict raises ValidationError before response is sent |
