## Out of Scope (Final)

| Feature | Reason | Reasoning Held? |
|---------|--------|-----------------|
| WebSocket real-time trace streaming | Mock runs complete in <1s; adds reconnect complexity and partial-state rendering bugs with near-zero value | ✓ Held |
| User accounts / authentication | Zero demo value for a single-presenter tool | ✓ Held |
| Cloud / production deployment | Localhost is the delivery format | ✓ Held |
| LLM-generated talking-point content | Non-deterministic; presenter loses confidence in what cards will say | ✓ Held |
| A2A remote transport as demo path | Infra dependency that can fail live; local is sufficient to demonstrate the protocol | ✓ Held |
| Editable scenarios via UI | Form validation + persistence complexity disproportionate to value | ✓ Held |
| OpenTelemetry / Jaeger / Zipkin export | External infra irrelevant for self-contained demo; native ZIP export is sufficient | ✓ Held |
| New API endpoints for trace visualization | All visualization should read existing `GET /api/runs/{id}` to prevent data path drift | ✓ Held |
| Separate `MCPToolCard` / `A2AAgentCard` components | Creates asymmetry and doubles maintenance; use one `CapabilityCard` with protocol prop | ✓ Held |
