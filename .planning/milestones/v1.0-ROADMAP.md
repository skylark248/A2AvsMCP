## Overview

This milestone deepened the A2A vs MCP demo platform from a working prototype into a polished, demo-day-ready comparison tool. Five phases shipped sequentially: stability foundation (all four modes run flawlessly without an API key), backend trace enrichment (data contract for downstream UI), new protocol-depth scenarios (multi-step + parallel-agent), comparison-clarity UI (swimlane timeline + side-by-side traces), and presentation polish (glossary popovers + role-first phrasing + failure walkthrough).

Each phase delivered a coherent, independently testable increment — the platform was demo-able after every phase.

- Lock demo day to `runtime=mock, transport=in_process` — only fully-tested, crash-safe transport path
- Pin `mcp>=1.27,<2` and `a2a-sdk==0.3.26`; defer SDK major migrations to v2
